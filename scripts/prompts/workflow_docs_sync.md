# 文件落實與架構同步流程 (Documentation Sync Workflow)

依據 `GEMINI.md` 的開發迭代規範，在「構想對齊 (Ideation)」完成後、撰寫程式碼之前，必須執行此工作流。

## 執行步驟：
1. **更新子模組文件**：
   - 根據共識，修改或新增 `./docs/architecture/` 目錄下的相關功能細節文件。
   - 確保文件符合 `./docs/doc_standards.md` 的 Markdown 格式與 YAML 標頭規範。
2. **全局架構同步 (ARCH.md)**：
   - 同步更新 `./docs/ARCH.md`，確保全局架構圖、依賴邊界與模組說明與最新設計完全一致。
   - 確保更新文件的 `last_updated` 日期欄位。
3. **變更驗證**：
   - 確認文件內沒有產生矛盾的架構描述。
   - 確保不會出現指向外部文件特定章節的依賴式註解思維。
4. **完工匯報**：
   - 總結本次更新的文件清單。
   - 詢問使用者是否可以正式進入「代碼開發 (Implementation)」階段。
