# 系統化除錯流程 (Systematic Debugging Workflow)

當使用者回報 Bug 或單元測試失敗時，請啟動此防禦性除錯工作流。

## 執行步驟：
1. **還原現場與資料收集**：
   - 要求檢視完整的 Error Log (包含終端機輸出或日誌檔內容)。
   - 查閱相關的原始碼與出錯的測試檔。
2. **假設與驗證**：
   - 提出導致錯誤的 2~3 種可能原因。
   - (可選) 透過 `grep_search` 或撰寫一小段臨時腳本來驗證假設。
3. **防禦性修補**：
   - 提出修復方案，並向使用者解釋該修補如何避免未來再次發生 (例如加入錯誤邊界檢查)。
   - 確保修補不破壞現有的生命週期 (Lifecycle) 與非同步事件 (EventBus) 設計。
4. **撰寫回歸測試**：
   - 在修復原始碼的同時，**必須**在對應的 `.test.ts` 中加入回歸測試案例，確保該 Bug 被永久封印。
5. **執行驗證與匯報**：
   - 透過 `bun test` 驗證修復結果，確認無誤後匯報給使用者。
