# L2 事實層 (Fact Layer / 百科全書)

L2 是系統的「百科全書區」，存放經過驗證的、長期穩定的事實資訊。

## 1. 核心定義
- **本體**: 結構化的事實知識庫。
- **作用域 (Scope) 與存儲路徑**:
    - **Global L2 (全域事實)**: 
        - 路徑: `workspace/memory/L2_global/`
        - 跨所有會話通用的知識（如開發規範、環境配置、架構定義）。
    - **Session L2 (會話事實)**: 
        - 路徑: `workspace/sessions/<sessionId>/L2_session/`
        - 僅屬於特定任務的驗證事實。
- **特性**: 
    - **准入門檻高**: 必須經過執行驗證。
    - **穩定性**: 內容不隨單次任務結束而消失。

## 2. 檢索優先級 (Lookup Strategy)
當 Agent 查詢事實時，系統遵循「局部優先」原則：
1. **Session L2**: 優先檢索當前會話產出的最新結論。
2. **Global L2**: 若會話內無紀錄，則檢索全系統通用事實。

## 2. 知識流動與維護
- **寫入優先級**: `ActingAgent` 確認的事實預設寫入 **Session L2**，以確保數據隔離。
- **升遷機制 (Promotion)**: 
    - 當事實具備跨專案通用價值時，可由 `ActingAgent` 判斷或用戶指令升遷至 **Global L2**。
    - 全域事實受到更嚴格的寫入保護，防止數據污染。

## 3. 使用方式
- 在投影至 L1 黑板時，系統會根據作用域標記 Key 的來源，確保 Agent 能識別事實的權限級別。
