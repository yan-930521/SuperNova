# L2 事實層 (Fact Layer / 百科全書)

L2 是系統的「百科全書區」，存放經過驗證的、長期穩定的事實資訊。

## 1. 核心定義
- **本體**: 結構化的事實知識庫。
- **內容**: 長期穩定且跨任務可複用的硬資訊 (Hard Facts)。
    - 範例: 伺服器配置、專案依賴版本、已驗證的資料庫 Schema。
- **特性**: 
    - **准入門檻高**: 必須經過執行驗證。
    - **穩定性**: 內容不隨單次任務結束而消失。

## 2. 知識維護 (Ingestion)
- **維護者**: `ActingAgent` 在 PDCA 的 `Act` 階段負責。
- **寫入機制**: 自動比對執行結果，確認具備長期價值且無衝突後，寫入 L2。

## 3. 使用方式
- `SupervisorAgent` 會在任務啟動前，從 L2 提取關鍵事實並在 L1 (黑板) 建立索引 Key。
