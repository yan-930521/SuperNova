# L3 SOP 層 (SOP Layer / 操作手冊)

L3 是系統的「操作手冊區」，存放可複用的流程知識與最佳實踐。

## 1. 核心定義
- **內容**: 包括任務工作流、前置條件、關鍵執行步驟、常見故障案例及對應的調試恢復策略。
- **範例**: "如何從 HuggingFace 下載數據集"、"API 異常處理標準流程"。

## 2. 純粹程序化設計 (Pure Procedural Design)
- **無變數原則**: SOP 內容保持為純粹的程序性知識（如：「獲取伺服器連線密鑰」）。
- **語義對齊 (Semantic Alignment)**: Agent 在執行 SOP 時，不依賴硬編碼的變數名匹配。
    - **對齊邏輯**: 將 SOP 步驟描述與 L1 黑板中的 **描述 (Description)** 同時提供給 LLM。
    - **判斷**: LLM 根據兩者的語義關聯，自主判斷哪個黑板 Key 存放了執行該 SOP 步驟所需的具體內容。
- **優點**: 實現了「邏輯與數據」的徹底解耦，讓同一套 SOP 能在完全不同的變數命名環境下運行。

## 3. 觸發機制
- `PlanningAgent` 在進行規劃時，會優先檢索 L3，將現有的 SOP 作為規劃的基石或模板。
