# L3 SOP 層 (SOP Layer / 操作手冊)

L3 是系統的「操作手冊區」，存放可複用的流程知識與最佳實踐。

## 1. 核心定義
- **內容**: 包括任務工作流、前置條件、關鍵執行步驟、常見故障案例及對應的調試恢復策略。
- **範例**: "如何從 HuggingFace 下載數據集"、"API 異常處理標準流程"。

## 2. 純粹程序化設計 (Pure Procedural Design)
- **無變數原則**: SOP 內容應保持為純粹的程序性知識，**嚴禁包含具體變數名或數據佔位符**（如 `{{db_port}}`）。
- **動作導向**: 僅描述動作序列、邏輯判斷與執行標準。例如：「步驟一：獲取資料庫連線資訊；步驟二：執行連線測試」。
- **語義對齊 (Semantic Alignment)**: Agent 在執行 SOP 時，應具備根據 SOP 的語義描述，自主在 L1 黑板中尋找並對齊最匹配的 Key 及其 Value 的能力。
- **優點**: 極大化 SOP 的跨環境複用性，實現「邏輯與數據」的徹底解耦。

## 3. 觸發機制
- `PlanningAgent` 在進行規劃時，會優先檢索 L3，將現有的 SOP 作為規劃的基石或模板。
