# L1 Cache (黑板系統 / Blackboard)

L1 是系統的當前工作空間，扮演著「CPU 快取」與「圖書館目錄檢索台」的角色。

## 1. 核心定義
- **本體**: 即系統的 **Blackboard (黑板)**。
- **內容**: 存放當前任務執行所需的所有變數、狀態描述、即時參數。
- **注入策略**: **Key-Only 模式**。
    - 為了極大化節省 Prompt Token，注入 Prompt 的內容僅包含變數的 **Key (鍵名)** 與簡短描述。
    - 範例：`- db_connection_status: 数据库连接状态标识`

## 2. 存取與預載入機制
- **預載入 (Pre-loading)**: 當任務啟動時，`SupervisorAgent` 會根據任務領域預先在黑板 (L1) 注入：
    - **L2 事實索引**: 約 20 條最相關的長期事實 Key（僅包含 Key 與簡短描述）。
    - **L3 SOP ID**: 指向相關操作手冊的 ID 或路徑指標。
- **按需加載 (On-demand)**: Agent 在 Prompt 中看到這些 Key 或 ID 後，若判斷需要其具體內容 (Value/全文)，必須主動呼叫 `read_blackboard(key)` 或 `fetch_sop(id)` 工具。
- **引用關聯**: 黑板上的事實 Key 應作為指向 L2 的「動態指針」，確保讀取到的是 L2 最新的數據。

## 3. 工具鏈支援
- `write_blackboard(key, value)`: 寫入或更新黑板狀態。
- `read_blackboard(key)`: 獲取黑板變數的具體值。
- `list_keys()`: 列出當前黑板所有可用的 Key。
